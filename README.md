# Карточка товара Teaboom.ru

Небольшой проект HTML/CSS/JS для карточки товара «Ананасовый улун».

## Структура проекта
- `index.html` — разметка карточки товара.
- `css/styles.css` — стили, цвета, размеры, адаптивность.
- `js/script.js` — переключение фасовок, обновление цены и артикула.
- `img/ananas-ulun.jpg` — изображение товара.

## Как запустить
1. Откройте папку проекта в VS Code.
2. Можно открыть файл `index.html` напрямую в браузере.
3. Или запустить локальный сервер:

```bash
cd c:\Users\gorba\OneDrive\Desktop\CARD
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

Либо используйте расширение Live Server в VS Code.

## Что умеет страница
- Отображает товар, артикул, цену со скидкой и старую цену.
- Переключает фасовки, обновляя цену и артикул.
- Поддерживает адаптивную верстку для мобильных и планшетов.
- Кнопка «В корзину» меняет стиль при наведении.
